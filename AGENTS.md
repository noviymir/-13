# Работа с проектом «Палата № 13»

Пользователь указал репозиторий https://github.com/noviymir/Palata-13 и попросил синхронизировать с ним все файлы проекта после изменений. Основная ветка — main.

- Работайте в текущем проекте, сохраняйте инструкции и решения пользователя из чата.
- Источник игрового мира — читаемый UTF-8 файл «карта мира.txt». После его изменения выполняйте `node build-world.cjs` и включайте обновлённый world-data.js в те же изменения.
- Сохраняйте запуск через index.html без выбора файлов и без установки программ для игрока.
- Выполняйте подходящие проверки. Основные: tests.cjs, tests-map.cjs, tests-secrets.cjs, tests-events.cjs, tests-music.cjs и tests-loading.cjs.
- Перед синхронизацией проверяйте git status и diff. Не включайте секреты, токены и временные файлы.
- Подготовленные изменения фиксируйте понятным коммитом и отправляйте в указанный origin обычным push либо через подключённый GitHub. Синхронизируйте все новые и изменённые файлы, включая media, сохраняя историю коммитов. Не используйте force push и не перезаписывайте чужую историю. Если появились удалённые изменения, сначала изучите их и сохраните обе стороны.
- Если авторизация GitHub недоступна, сохраняйте выполненную локальную работу и точно сообщайте, что ещё не загружено. Не сохраняйте пароли или токены в файлах проекта.
- Пользователь разрешил публикацию игры через GitHub Pages из ветки main. Сохраняйте работу этой публикации при дальнейших изменениях.
